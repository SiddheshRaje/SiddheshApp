# Portfolio Projects

Keep each portfolio project isolated in its own folder so project-specific
components, hooks, utilities, types, and assets do not get mixed with the
shared portfolio code in `src/components`.

## Projects

- `blockchain-transaction-app/` — Ethereum Decentralized App code.
- `cryptocurrency-tracker/` — Cryptocurrency Tracker code.

Shared components that are used by the main portfolio should remain in
`src/components`.
